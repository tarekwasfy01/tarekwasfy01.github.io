# Public support and privacy site

This is the publish-only website folder. It contains the support home page,
thirteen app-specific privacy policies, and `.nojekyll` for static hosting.

## Publish with GitHub Pages

Create a **public** repository named `tarekwasfy01.github.io` under the
`tarekwasfy01` GitHub account. Upload the **contents of this directory** to the
repository root. Do not upload the parent `AppStore-Preparation` directory; it
contains internal preparation files.

In the repository, open **Settings → Pages**. Under **Build and deployment**,
choose **Deploy from a branch**, select the default branch and `/(root)`, then
save. GitHub publishes the user site at `https://tarekwasfy01.github.io/`.
